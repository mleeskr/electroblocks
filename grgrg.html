ElectroBlocks Modular Learning System

ElectroBlocks uses physically interlocked electronic modules that simulate real embedded systems architecture. Every block joins a shared power and communication bus, allowing modules to appear and disappear dynamically in the dashboard as hardware is connected.

Circuit Loop & Current Flow

When a piano key is pressed, the microswitch closes the electrical circuit. Current flows from the VCC rail through the switch and back into the ground return path.

1. Button pressed
2. Circuit closes
3. GPIO pin changes state
4. ESP32 detects interrupt
5. Firmware encodes note event

Real-Time Data Transmission

ElectroBlocks transmits note and RGB data through Firebase in real time. Every hardware action becomes a live packet traveling through the network infrastructure.

WiFi Synchronization Layer

The WiFi block acts as the communication gateway between the hardware modules and the web dashboard. Once the ESP32 sends JSON packets through Firebase, the browser updates the UI automatically via live listeners.
