💡 Learn — How ElectroBlocks Works

Welcome to ElectroBlocks! 🎉

ElectroBlocks is a set of colourful snap-together electronic modules that talk to the internet! Each block has a job, and when you connect them together, they create a working electronic system that you can see live on this screen.

⚡
Power Block

Always on! Sends electricity to all the other blocks through the snap rail.

🌐
WiFi Block

Connects the system to the internet so data can travel to the cloud.

🎹
Piano Blocks

Each piano block has 3 keys. Press them and the ESP32 inside detects the signal!

🎨
RGB Colour Blocks

Three blocks controlling red, green and blue light. Mix them to make any colour!

⚡ How the Circuit Loop Works

Electricity flows in a loop — it needs a complete path from the battery through all the components and back again. Like water in a circle!

⚡ VCC Power Rail (3.3V)
Switch State:
OPEN (no current)
🔴 OPEN CIRCUIT

Switch open = circuit broken = electrons can't flow = no current!

🟢 CLOSED CIRCUIT

Switch closed = circuit complete = electrons zoom through = current flows!

🔌 Button Press & GPIO Detection

GPIO stands for General Purpose Input/Output — these are special pins on the ESP32 chip that can detect if electricity is flowing or not. When you press a key, you close a circuit through one of these pins!

🎹 Piano Key Pressed
⚡ GPIO Pin Goes LOW
🖥️ ESP32 Fires Interrupt
📤 Data Sent to WiFi
🧠 What is an Interrupt?

An interrupt is like a doorbell for the ESP32's brain. Instead of constantly checking "is the button pressed? is it pressed?", the ESP32 can do other work and the button literally interrupts it the moment it's pressed — much faster and smarter!

🖥️ ESP32 & WiFi Transmission

The ESP32 is a tiny but powerful computer chip with built-in WiFi. It reads the piano keys and RGB dials, packages the data, and sends it wirelessly to the internet!

🎹 Key Event
⚙️ ESP32 CPU
📦 JSON Pack
📡 WiFi Send
☁️ Internet
⚙️
Step 1 — Detect

GPIO interrupt fires when a piano key is pressed. The CPU immediately knows which pin was triggered.

📦
Step 2 — Package

ESP32 creates a small JSON message like: {"note":"C4","time":12345}

📡
Step 3 — Transmit

The WiFi module sends the data as radio waves to your home router, and off it goes to the internet!
