💡 Space Academy — How It Works!

Welcome, Junior Engineer! 🎉

ElectroBlocks are magical, colorful blocks that clip together to build working computers that talk to the internet! Every block has its own superpowers.

⚡
Power Core Block

The boss! It pumps electricity out through its metal side-snaps to awaken other blocks.

🌐
WiFi Gateway Block

The space radio! It grabs information from the blocks and sends it beaming up to the internet.

🎹
Music Piano Blocks

These blocks contain secret buttons. Pressing a button sends data flying along the row.

⚡ The Electrical Rollercoaster Loop

Electricity is a tiny crew of working electrons. They can only move if there is a smooth, continuous path to run around. Think of it like a train track circuit!

⚡ Power Highway (3.3 Volts)
Key/Switch:
OPEN TRACK (Electrons Stopped)
🔴 UNLINKED BREAK

When buttons are up, the track is broken. Electrons stop dead in their tracks!

🟢 COMPLETE TRACK

When you push a button, the gate closes! Electrons sprint through happily.

🔌 How the Chip Feels Your Touch

Inside the controller block is a smart brain chip with tiny sensation ports called **GPIO pins**. Pushing down on a piano key flips an electric signal line that triggers a quick reflex!

🎹 Push Key Down
⚡ Wire Connects to Pin
🧠 Chip Brain Feels Switch Line
📤 Quick Code Package Fired

🖥️ Meet the Microcomputer Brain

The main block uses a tiny computer chip called an **ESP32**. It's incredibly small but packs an ultra-fast brain processor and an internal wireless radio engine!

🎹 Press
🧠 Process
📦 Pack Data
📡 Beam Radio

It captures your inputs, turns them into structured letters and labels (called JSON packets), and shoots them through space as light-speed invisible radio waves to your house router!

🔥 Cloud Memory Sync

Your home router forwards the data directly into a dynamic storage room on the cloud called **Firebase**. It keeps track of every connected block automatically.

🌐 Instant Update Shimmer

The screen is connected to the cloud with an open pipeline listener. The millisecond the database changes, your browser updates instantly without needing a page refresh!
